# Contributing

Thank you for considering a contribution.

- Read the README and existing project structure before changing files.
- Open an issue or discussion before substantial changes.
- Keep pull requests focused and explain their purpose.
- Do not submit credentials, personal data, confidential material, or content you lack permission to share.
- Confirm that code, datasets, prompts, images, fonts, and other assets may legally be contributed and redistributed.
- Update documentation and add or update tests when applicable. State clearly when tests were not run.
- Preserve third-party notices and identify new dependencies and their licenses.

By submitting a contribution, you confirm that you have the right to submit it under the repository's applicable terms. Ask the maintainer if ownership or permission is unclear.
